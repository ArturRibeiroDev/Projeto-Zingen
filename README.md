# 🎵 Zingen — Landing Page

Landing page completa no estilo SaaS com hero section animada, cards de features, tabela de preços, prova social e seção de download.

## 🚀 Tecnologias

| Tecnologia | Função |
|---|---|
| **HTML5** | Estrutura semântica |
| **CSS3** | Estilização modular por seção |
| **JavaScript** | Interatividade |

## ✨ Funcionalidades

- ✅ Hero section com layout visual
- ✅ Seção de features com cards
- ✅ Pricing tables
- ✅ Seção social (prova social)
- ✅ Seção de download com CTA
- ✅ Botões e micro-interações
- ✅ CSS modular (15+ arquivos por seção)

## 🏗️ Estrutura

```
/styles
├── global.css, index.css
├── header.css, footer.css
├── hero.css, sections.css
├── cards.css, features.css, pricing.css
├── buttons.css, social.css, download.css
├── about.css, utility.css
```

## 🚦 Como Rodar

Abra `index.html` no navegador.
